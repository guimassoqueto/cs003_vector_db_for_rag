## What you will learn

In this lab, you will implement text similarity search using embeddings in Chroma DB, a database system designed for managing and querying text data efficiently.

You will create a collection on a Chroma server and populate it with a set of sample text documents, where each document has a unique ID and an embedding generated by the SentenceTransformer embedding function. Then you will perform a similarity search for a query term, and for several query terms in a single call, retrieving the top three documents most similar to each.

## Learning objectives

After completing this lab, you will be able to:

- Integrate Chroma DB into applications for storing and querying text data.
- Generate text embeddings for text documents using Chroma DB's SentenceTransformer embedding function.
- Implement similarity search functionality to compute similarity scores between query embeddings and document embeddings.
- Display top-ranked documents similar to a given query term.

1. Import the `chromadb` package and its embedding functions. The embedding model and the server address come from `app/config/envs.py`, which the other Chroma lessons share: `EMBEDDING_MODEL` is `"all-MiniLM-L6-v2"`, and the server is `localhost:8000`.

    ```python
    import chromadb
    from chromadb.utils import embedding_functions

    from app.config.envs import CHROMA_HOST, CHROMA_PORT, EMBEDDING_MODEL

    COLLECTION_NAME = "my_grocery_collection"
    ```

2. `connect()` creates the client that interacts with the Chroma server from Task 1.

    ```python
    def connect() -> chromadb.ClientAPI:
        """Connect over HTTP to the Chroma server started by this folder's docker-compose.yml.

        The lab's chromadb.Client() is in-memory instead, and forgets everything on exit.
        """
        return chromadb.HttpClient(host=CHROMA_HOST, port=CHROMA_PORT)
    ```

3. `get_grocery_collection()` creates the collection, with its distance metric and embedding function.

    ```python
    def get_grocery_collection(client: chromadb.ClientAPI) -> chromadb.Collection:
        """Return the grocery collection, creating it on first use.

        It compares embeddings by cosine distance, and embeds documents and queries with a
        SentenceTransformers model. get_or_create lets the script run again: the configuration
        only applies the first time, when the collection is actually created.
        """
        embedding_function = embedding_functions.SentenceTransformerEmbeddingFunction(model_name=EMBEDDING_MODEL)
        return client.get_or_create_collection(
            name=COLLECTION_NAME,
            metadata={"description": "A collection for storing grocery data"},
            configuration={"hnsw": {"space": "cosine"}, "embedding_function": embedding_function},
        )
    ```

    - `"hnsw": {"space": "cosine"}` makes the collection compare embeddings by cosine distance.
    - `"embedding_function"` makes Chroma embed both the documents and the query terms with the SentenceTransformer model, so the code only ever passes text.
    - `get_or_create_collection` returns the existing collection on a second run, where `create_collection` would fail because the collection already exists.

::page{title="Task 5: Perform a similarity search"}

`search()` in `vector_store.py` queries the collection and returns its results as one list of `Match` per query term.

```python
@dataclass(frozen=True)
class Match:
    """A document returned by a similarity search."""

    id: str
    text: str
    distance: float  # cosine distance: 0 means same direction, lower is more similar
```

```python
def search(collection: chromadb.Collection, queries: str | list[str], n_results: int = 3) -> dict[str, list[Match]]:
    """Return the n_results documents closest to each query, most similar first.

    Chroma answers a query with parallel lists, one per query term: results["ids"][q][i]
    goes with results["documents"][q][i] and results["distances"][q][i]. This regroups
    them into one list of Match per query term.
    """
    if isinstance(queries, str):
        queries = [queries]
    results = collection.query(query_texts=queries, n_results=n_results, include=["documents", "distances"])

    matches_by_query = {}
    for q, query in enumerate(queries):
        rows = zip(results["ids"][q], results["documents"][q], results["distances"][q], strict=True)
        matches_by_query[query] = [Match(doc_id, text, distance) for doc_id, text, distance in rows]
    return matches_by_query
```

- `query_texts` takes a list, so a single call can search for several query terms. A single string is wrapped in a list first.
- `n_results` is the number of closest documents to return for each query term.
- `include=["documents", "distances"]` asks only for what gets displayed, leaving the metadata out.
- Chroma returns parallel lists nested per query term. The outer loop walks the query terms, and `zip` pairs each document's ID, text and distance into a `Match`. The result looks like `{"milk": [Match(...), Match(...), Match(...)]}`.
- The distance is the cosine distance between the query and the document embeddings: lower means more similar.

::page{title="Task 6: Display the most similar documents"}

1. `print_matches()` in the entry script prints the matches for one query term, or a message when none were found.

    ```python
    def print_matches(query: str, matches: list[Match]) -> None:
        """Print the documents closest to a query, most similar first."""
        print(f'[top {TOP_K}, "{query}"]')
        if not matches:
            print(f'  No documents found similar to "{query}"')
        for match in matches:
            print(f'  {match.id:<8} {match.distance:.4f}  "{match.text}"')
    ```

2. `main()` searches for one query term, then for two in a single call, and prints the top three matches for each.

    ```python
        # Similarity search: the documents closest to one query...
        for query, matches in search(collection, "milk", n_results=TOP_K).items():
            print_matches(query, matches)

        # ...or to several queries in a single call
        for query, matches in search(collection, ["red", "fresh"], n_results=TOP_K).items():
            print_matches(query, matches)
    ```

In this lab, you learned the following:

- **Chroma DB integration:** `vector_store.py` connects to a Chroma server with `chromadb.HttpClient` and creates a collection configured for cosine distance, with a SentenceTransformer embedding function.

- **Data handling:** `groceries.py` defines the grocery items with their IDs and metadata, and `main()` adds them to the `my_grocery_collection` collection. The SentenceTransformer embedding function generates the embeddings automatically when the documents are added.

- **Similarity search:** `search()` retrieves the top three documents closest to each query term, for one term (`"milk"`) or several in one call (`["red", "fresh"]`), and regroups Chroma's nested results into `Match` objects. `print_matches()` displays each match's ID, cosine distance and text.
